## ④ 상황 인식 추천 연결 (가이드라인 ④·⑤ — 빠져 있던 기능)
가이드라인 ④는 문서(예시 대화)에만 있고 코드에는 없었어요. 이번에 서버·프롬프트·화면을 모두 연결했어요.

| 부분 | 어디 | 동작 |
|---|---|---|
| 목적 읽기 (코드, 토큰 0) | `agent/recs.py` `classify` | 가격 · 양 · 품질 · 경험 · 판단 없음 + 확신도 상/중/하 |
| 상황 한 줄 | 프롬프트 (`assistant.build_system`) | 추천할 때 ④ 표의 문장 틀로 답을 시작 (예: "월말이라 '가격' 쪽으로 봤어요.") |
| rec_id | `service.chat` | 후보 카드가 있는 추천 답마다 `rec` = {rec_id, situation{domain, read, read2, confidence, line}, shown[{id, kind}]} |
| 목적 버튼 4개 | 화면: 추천 카드 묶음 바로 아래 | 더 싸게 · 더 많이 · 더 좋게 · 안 해본 걸로 → 정정(-1점, 정답 목적 확정) 기록 + 그 목적으로 다시 고르기 |
| 선택 | 화면: '이 상품 선택하기' | choose 기록 (읽은 목적과 후보 성격이 같으면 +1) |
| 만족도 1~5 | 화면: 추천에서 만든 정산방의 그룹 카드, '정산 인증서 보기' 위 · 지급이 끝난 뒤 한 번 | rate 기록 ((점수-3)/2) · 그룹방은 멤버마다 한 번 |
| API | `POST /api/pie/feedback` | `{rec_id, event: choose|correct|rate, candidate?, purpose?, satisfaction?}` |
| 기록 | `data/pie_feedback.jsonl` + 베타 데이터 폴더 | 사람은 uid로만 (이메일·이름 없음) — ⑤ 채점·오답 노트의 재료 |

④ '판단할 점'에서 정한 것: 버튼을 누르면 후보를 새로 뽑아요(AI 호출 1회) · 그룹방 만족도는 멤버마다 받아 평균할 수 있게 모두 기록 ·
여행은 검색 도구가 없어 후보 카드가 안 뜨므로 버튼도 자연히 안 보여요 · 엔드포인트 이름은 제안대로. 선택(+1)·만족도 점수 환산은 원본 보상 표를 확인해 맞춰야 해요.

확인: `python tests/rec_check.py` ✓ 전체 통과 (상황 판단 4가지가 가이드라인 예시 ex-034·035·039·045 문장과 같음 · rec_id · 피드백 3종 · 잘못된 값 거절 · 비식별 기록 · 정산방 연결)

## 지갑 전체 흐름 검수 (2026-09-30)
사용자 제보 'HTTP 530' → 앱 오류가 아니라 **터널은 켜져 있는데 서버가 꺼져 있을 때** Cloudflare가 보내는 오류 (서버 PC에서 localhost:8000 연결 거부 확인).
이어서 지갑 흐름 전체를 **화면 지갑 코드(sp-bridge.js) 그대로 + 로컬 체인 + 실제 체인 모드 서버**로 검사하는 `tests/wallet_e2e_check.py`를 만들었어요.

| 단계 | 결과 |
|---|---|
| 연결 (`connect()`) · 다른 네트워크 + 추가 거절 → 안내 | ✓ |
| ETH 0인 새 지갑 등록 → 가스 0.002 ETH 자동 도착 | ✓ 0.5초 |
| PIE 충전 | ✓ 100,000 |
| 정산 등록 → 대기 멤버 승인·예치(MetaMask 서명 2단계) → locked → 이의제기 기간 뒤 자동 지급 | ✓ paid (4초) |
| MetaMask 계정이 등록 지갑과 다름 → 안내 | ✓ |

고친 것:
- 결제 버튼을 결제자·이미 낸 사람이 눌러도 **트랜잭션을 보내기 전에** 막고 안내 ("결제자는 예치하지 않아요…" · "이미 결제·승인한 정산이에요") — 거절될 트랜잭션에 가스를 쓰지 않게
- 컨트랙트 거절 이유가 영어 원문("execution reverted…", "missing revert data")으로 보이던 것 → 한국어 안내 ("not a member" → 예치할 몫이 없어요 · 그 밖 → 블록체인이 거절했어요, 새로고침해 정산 상태 확인)

실행: `anvil` → `npm install ethers@6 --prefix <폴더>` → `python tests/wallet_e2e_check.py --ethers <폴더>` (Sepolia에는 아무것도 보내지 않음)
